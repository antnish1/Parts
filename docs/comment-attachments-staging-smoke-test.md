# Comment Attachments Staging Smoke Test

Use this checklist after applying migration `010_add_test_comment_attachments_storage.sql` and deploying the attachment Edge Functions.

## Required staging setup

- Migration `010_add_test_comment_attachments_storage.sql` has been applied.
- Private Storage bucket `test_order_comment_attachments` exists.
- Table `test_order_comment_attachments` exists.
- Edge Function `comment-attachment-upload-action` is deployed.
- Edge Function `comment-attachment-link-action` is deployed.
- Service role key is configured only as a Supabase function secret.
- No service role key is present in frontend code or Vercel frontend environment variables.

## Upload tests

- Login as a developer user.
- Open a staging `TEST-*` order in Order Detail.
- Add a user comment.
- Use the compact `Attach file` link under the comment.
- Attach one small JPG or PDF.
- Confirm the UI shows `Attachment uploaded.`
- Confirm the attachment appears under the same comment.
- Confirm `COMMENT_ATTACHMENT_ADDED` appears in order activity after refresh.

## Download tests

- Click the compact `Download ...` link under the comment.
- Confirm the file opens or downloads successfully.
- Confirm the download uses a signed link generated by `comment-attachment-link-action`.
- Confirm a user without access to the order cannot generate the signed link.

## Validation tests

- Upload an unsupported file type and confirm it is rejected.
- Upload a file larger than 10 MB and confirm it is rejected.
- Upload more than 5 files to one comment and confirm the extra upload is rejected.
- Confirm the object path does not contain customer phone numbers, machine numbers, or other business identifiers from the order.

## Role tests

- Branch user can upload and download attachments only for their own branch order.
- Branch user cannot download another branch order attachment.
- Admin can download attachments on accessible staging orders.
- Manager can download attachments on accessible staging orders.
- Super user can download attachments on accessible staging orders.
- Developer can upload and download attachments on staging orders.

## Regression tests

- Order Detail still loads comments when there are no attachments.
- Order Detail still loads comments if attachment metadata query returns no rows.
- Existing order comments remain visible.
- Activity panel remains collapsed by default.
- Print view still focuses on order details and does not expose upload controls.

## Known limitation

Attachment removal is not implemented yet. Current staging workflow supports upload and signed download only.
